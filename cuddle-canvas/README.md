# Cuddle Canvas ♡

A cute real-time collaborative drawing canvas built with TypeScript, Express and WebSockets.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000 in two browser tabs and draw at the same time.

## Features

- Real-time stroke synchronization with WebSockets
- Shared rooms
- Live participant list
- Pencil + eraser
- Color palette and brush size
- Undo for local strokes
- Stickers
- PNG export
- Responsive cute UI

## Room links

Use `?room=my-room` in the URL to create/join a named room.
